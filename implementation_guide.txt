# RestoSaathi Dashboard - Implementation Guide

## Project Setup

### 1. Create Next.js Project
```bash
npx create-next-app@latest resto-saathi --typescript --tailwind --eslint
cd resto-saathi
```

### 2. Install Dependencies
```bash
npm install lucide-react
```

### 3. Tailwind CSS Configuration
Ensure your `tailwind.config.js` includes:
```javascript
module.exports = {
  content: [
    './app/**/*.{js,ts,jsx,tsx,mdx}',
    './components/**/*.{js,ts,jsx,tsx,mdx}',
  ],
  theme: {
    extend: {
      colors: {
        'navy': '#0B2545',
        'resto-orange': '#FF6B00',
        'dark-slate': '#1E293B',
      },
    },
  },
  plugins: [],
}
```

### 4. File Structure
```
resto-saathi/
├── app/
│   ├── layout.tsx
│   ├── page.tsx              (Dashboard page)
│   └── globals.css           (Tailwind directives)
├── components/
│   ├── RestoDashboard.jsx    (Main dashboard component)
│   ├── Sidebar.jsx           (Optional: Extract sidebar)
│   ├── Header.jsx            (Optional: Extract header)
│   └── KPICard.jsx           (Optional: Extract KPI card)
└── tailwind.config.js
```

## Component Integration

### Option 1: Direct Integration (Simple)
In your `app/page.tsx`:
```typescript
import RestoDashboard from '@/components/RestoDashboard';

export default function Home() {
  return <RestoDashboard />;
}
```

### Option 2: Modular Approach (Recommended for production)
Break down the dashboard into smaller components:

```
components/
├── Dashboard/
│   ├── index.jsx
│   ├── Sidebar.jsx
│   ├── Header.jsx
│   ├── KPIGrid.jsx
│   ├── RecentOrders.jsx
│   └── types.ts
```

## State Management

The component uses React hooks:
- `sidebarOpen`: Boolean state for sidebar toggle
- `isOnline`: Boolean state for online/offline status
- `selectedBranch`: String state for branch selection

### To integrate with Redux/Context (recommended for production):
```typescript
import { useDispatch, useSelector } from 'react-redux';

const sidebarOpen = useSelector(state => state.ui.sidebarOpen);
const dispatch = useDispatch();
```

## API Integration Points

### To connect with backend APIs:

1. **KPI Data Fetching**

## Responsive Breakpoints

- **Mobile (< 768px)**: 
  - Sidebar collapses to icon-only
  - KPI cards stack vertically
  - Table scrolls horizontally
  
- **Tablet (768px - 1024px)**:
  - Sidebar can toggle
  - KPI cards show 2 per row
  - Table shows all columns
  
- **Desktop (> 1024px)**:
  - Sidebar always visible
  - KPI cards show 4 per row
  - Full table display with optimal spacing

## Troubleshooting

### Icons not showing?
- Ensure `lucide-react` is installed: `npm install lucide-react`

### Tailwind styles not applying?
- Check `content` paths in `tailwind.config.js`
- Run `npm run build` to rebuild

### Sidebar toggle not working?
- Ensure `'use client'` directive is at top of component
- Check React version compatibility
